# Aizhigit Stepper

Статический адаптивный информационный сайт для продукта Stepper.

## Запуск

Откройте `index.html` в браузере. Сервер не обязателен: все стили, скрипты и изображение лежат локально.

## Структура

- `index.html` - разметка страницы.
- `styles.css` - адаптивный минималистичный дизайн и анимации.
- `script.js` - i18n RU/KY, мобильное меню, FAQ, reveal-анимации и демо-обработка формы.
- `assets/stepper-hero.png` - сгенерированное product/lifestyle изображение для hero.

## Что подключить перед запуском

Форма сейчас показывает локальное уведомление. Для продакшена подключите отправку в CRM, Telegram, WhatsApp или backend endpoint в обработчике `data-lead-form` в `script.js`.
